# HexaDecipad-V3

**HexaDecipad-V3** is a custom-designed macropad built for **[Hack Club Stardance](https://stardance.hackclub.com/)**—a summer engineering program run by Hack Club in partnership with NASA, AMD, and GitHub. 

After running into some issues with the previous versions, Version 3 is redesigned from the ground up to be reliable and highly functional!

---

## Hardware Features

- **Microcontroller:** Seeed Studio XIAO (compatible with XIAO RP2040, SAMD21, etc.)
- **Keys:** 10x Cherry MX-compatible hotswap sockets (using `MX100H` footprints)
- **Rotary Encoders:** 2x Alps EC11-style rotary encoders with integrated push switches
- **Key Matrix Diodes:** 12x 1N4148 through-hole diodes (`DO-35` package)
- **PCB Design:** Fully designed in KiCad (files located in the `PCB/` directory)
